# Техническое задание: Калькулятор стоимости владения праворульным автомобилем

## 1. Цель проекта
Создание веб-сервиса для расчета реальных затрат на владение праворульным автомобилем в России на срок 1-5 лет.

## 2. Роли пользователей
- Гость: использование калькулятора с демо-данными
- Авторизованный пользователь: сохранение расчетов, история
- Администратор: управление базой моделей и цен

## 3. Модели данных
1. **RightHandCar**: Праворульная модель авто (Toyota, Nissan и др.)
2. **OwnershipCalculation**: Расчет пользователя
3. **CostItem**: Статья расходов (таможня, адаптация, страховка и т.д.)

## 4. Ключевой функционал
* Выбор модели авто из каталога
* Расчет таможенных пошлин по формуле РФ
* Расчет затрат на адаптацию под российские условия
* Визуализация расходов по годам
* Сравнение разных моделей авто

## 5. Внешние интеграции
* API ЦБ РФ для курса JPY/RUB
* Парсинг цен с Avito/Drom (опционально)
* Библиотеки: Pandas для анализа, Matplotlib для графиков
