# JDM Calculator - Техническое задание (Текущее состояние)

# Обзор проекта
JDM Calculator — веб-сервис для точного расчета полной стоимости владения праворульными автомобилями из Японии. Сервис учитывает все этапы от покупки на аукционе до доставки и оформления в России.

# Архитектура системы

# Технологический стек
Backend: Python 3.x, Django 4.x
Frontend: HTML5, CSS3, JavaScript, Bootstrap 5
База данных: PostgreSQL (планируется)
Хостинг изображений: ImgBB

# Бэкенд структура
URL маршруты
/ — главная страница (реализовано)

/calculation/create/ — страница создания расчета (заглушка)

/cars/ — каталог автомобилей (заглушка)

/api/currency/all/ — API курсов валют (частично реализовано)

# Передача параметров
Карточки автомобилей передают параметры через URL:
/calculation/create/?car=1&price=500000&year=1998&engine=2.5&rate=0.60

# Формула расчета
Цена в рублях = Цена в йенах × Курс JPY/RUB

# Обработка ошибок и надежность

Загрузка изображений
1.Попытка загрузки основного изображения
2.При ошибке — переход к резервным источникам
3.При отсутствии изображений — отображение плейсхолдера
4.Анимация переключения между изображениями

Курсы валют
1.Запрос к API /api/currency/all/
2.При ошибке — использование резервных данных
3.Сохранение в localStorage для offline-работы
4.Периодическое обновление данных

JavaScript ошибки
Graceful degradation при отключенном JavaScript
Проверка доступности DOM элементов
Обработка исключений с пользовательскими сообщениями

# Ограничения текущей реализации
Не реализованные компоненты:
  Бэкенд расчет — формула расчета только на фронтенде
  База данных — автомобили захардкожены в шаблоне
  Аутентификация — система пользователей отсутствует
  Каталог автомобилей — страница каталога является заглушкой
  Админ-панель — отсутствует интерфейс управления
  История расчетов — не сохраняются результаты
  Экспорт данных — отсутствует экспорт в PDF/Excel
